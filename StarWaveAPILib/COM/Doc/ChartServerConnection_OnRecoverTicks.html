OnRecoverTicks event

           

回補的成交資料.

當第一次呼叫Subscribe時,ChartServer會主動回補最後的100筆成交資料.

如果還需要補完整的成交資料,建議分區段呼叫RequestTicks,可補回今日的完整成交明細.

Syntax

Sub object_OnRecoverTicks(Exchange As String, Symbol As String, Ticks As ITickInfoList)

The OnRecoverTicks event syntax has these named arguments:

Part Description
ExchangeString,交易所
SymbolString,商品
TicksITickInfoList,回補的成交明細
