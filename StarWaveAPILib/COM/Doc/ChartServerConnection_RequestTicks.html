RequestTicks method

           

向Chart Server要求特定商品的,特定範圍的成交明細.

Return Type

A Boolean value.

Syntax

object.RequestTicks(Contract As ISecurityDefinition, Begin As Long, End As Long)

The RequestTicks method syntax has these parts:

Part Description
object An expression evaluating to an object of type ChartServerConnection.
ContractISecurityDefinition 要求成交明細的商品.
BeginLong 起始的成交ID(TickInfo的ID屬性)
EndLong 終止的成交ID.
