GetSymbol method

           

取得商品代碼.

Return Type

A String value. 傳回商品代碼.

Return Type

A Boolean value.

Syntax

object.GetSymbol(Exchange As String, Index As Long)

The GetSymbol method syntax has these parts:

Part Description
object An expression evaluating to an object of type StarWaveConnection.
Exchange 只定的交易所代碼.
Index 此交易所中的第幾個商品.
